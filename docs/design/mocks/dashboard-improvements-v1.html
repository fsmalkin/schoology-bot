7Sidebar — tighter labels, two-section split, footer status

The sidebar currently has three verbose nav items in one flat section, a faint active state, and an empty bottom half. Proposed shrinks to two primary items, groups System into a Monitor footer row with the status dot baked in, adds a parent identity row, and brightens the active state with a brand accent. Recommended: proposed.

8Drawer header — one chip row instead of a five-line stack

When the review drawer opens, the header is 5 lines tall (eyebrow → title → status pill + middot + due date → Schoology link → optional reason text) before the first action is visible. Proposed compresses to 3 lines with the most important metadata in a single chip row, parallel-label save buttons, and a "Last synced" timestamp. Recommended: proposed.
