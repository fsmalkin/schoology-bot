Reminder confirmation — reject past dates, echo back the time

🔴✓ verified bug

Verified via curl: remindAt:"2000-01-01" returns {ok:true} and the reminder silently never fires. Proposed rejects past times and echoes the parsed time back so the parent catches a 7 AM/PM or DST mistake before saving. This is the UI surface for audit §0 fix #3.
